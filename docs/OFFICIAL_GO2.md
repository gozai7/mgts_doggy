## Запуск

Требуется собранный `mgts-competition-glim:gpu`. На тестовом ноутбуке выполните `export DOCKER_CONTEXT=mgts`.

```bash
make go2-rviz PHASE=localization      # исходные измерения B в RViz, по кругу
make go2-map                         # GLIM на A
make go2-locate                      # исходный холодный поиск и NDT на карте GLIM
make go2-live RUN_NAME=demo-01        # карта из штатных облаков A, слепой старт и NDT на B при 1×
make go2-result RUN_NAME=demo-01      # RViz с записанным результатом demo-01
```

Для нового живого прогона выберите свободное имя. Без RUN_NAME оно формируется по времени. Базовый `go2-locate` на этих данных завершился ошибкой связывания последовательных сканов. На уже созданном неуспешном checkpoint раннер сохраняет диагностику и отказывается перезаписывать каталог.

## Что входит в замер

В GLIM подаются записанные `cloud_base` и `utlidar/imu`. Поворот IMU оценён по сопоставлению гироскопа и направления тяжести с одометрией A. Для плеча IMU принято положение центра лидара. Медианная норма ускорения составляет 9,71 м/с² на A и 9,80 м/с² на B. Во всех сообщениях IMU три матрицы ковариации заполнены нулями. Использованы штатные параметры шума GLIM, отдельная шумовая калибровка отсутствует.

В `go2-live` карта строится накоплением штатного `cloud_deskewed` из A. По первым 25 с B сопоставляются облака с учётом относительного перемещения по кинематической одометрии. Поиск проверяет альтернативные положения и курсы. После старта NDT получает `cloud_base` по исходным интервалам записи, одометрия даёт прогноз. Публикация каждого скана независима от результата предыдущего. Отклонённая регистрация учитывается как отсутствие подтверждённой позы. Ожидание начального окна и расчёт старта входят во время до первой позы. Построение A и загрузка карты в ноду выполняются до воспроизведения B.

В `results/<имя>/` сохраняются `timing.json`, `initialization.json`, `map.pcd`, `trajectory.tum` и `result_bag/`. Задержка считается от момента поступления записанного облака до ROS-сообщения с принятой позой. Время захвата лазерного скана к ней не прибавляется. Стенд — Ryzen 5 5600H, RTX 3060 Laptop. GLIM использует GPU, NDT_OMP — CPU.
