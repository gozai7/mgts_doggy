# Вернётся ли штатный AMCL к верной позе после переноса?

## Как воспроизведена потеря позы

У AMCL есть правильная начальная поза в карте — `(3,7 м; 2,5 м; 90°)`. Робот 25 с движется по окружности радиусом 1,2 м с центром в (2,5; 2,5) м, скоростью 0,42 м/с и угловой скоростью 0,35 рад/с. В момент переноса ко всем дальнейшим истинным координатам добавляются 5,4 м по X и 3,5 м по Y, ориентация сохраняется. Поэтому расстояние между точками двух окружностей при одинаковой фазе равно 6,44 м. Чистый контроль продолжает первую окружность. Лидар видит геометрию с фактического места. Идеальная относительная одометрия в обоих случаях продолжает исходное движение. [Генератор и метрики](контроль_переноса.py)

Карта размером 12 × 9 м, разрешением 0,05 м/пиксель, с началом в (0; 0). Внутренний край внешней стены проходит в 0,1 м от границы поля. Внутри четыре прямоугольных препятствия с разными положениями и размерами. Лидар расположен в центре `base_footprint`, даёт 360 лучей через 1°, полный оборот, диапазон 0,12–16 м. Каждый луч заканчивается на ближайшем пересечении с геометрией карты. Скан и одометрия синхронны, по 10 Гц, с длительностью записи 115 с. Первой метке ROS 1 с соответствует время маршрута 0 с. Внешний шум, IMU и крен отсутствуют. [Геометрия и генерация записей](контроль_переноса.py)

В обоих MCAP только `/scan` и `/odom`. Побайтовое сравнение сериализованных сообщений подтвердило совпадение всей одометрии и первых 250 сканов. Различаются ровно 901 скан начиная с метки ROS 26,0 с. В контейнер AMCL монтируются только карты, профиль, сенсорные записи и конфигурация. Вызов `--initial` один, при запуске. Карта, пакет, частота и параметры фильтра совпадают между вариантами за исключением `recovery_alpha_fast` и `recovery_alpha_slow`. В исходном конфиге они унаследованы от Nav2 и равны нулю. В опытном конфиге они равны 0,1 и 0,001. Все варианты используют `OmniMotionModel`, 500–3000 частиц, пороги движения по 0,05 м и 0,05 рад, пересэмплирование при каждом обновлении. [Штатный конфиг](../../configs/amcl.yaml) · [Проигрыватель](../../solver/solve.py) · [Параметры Nav2 1.3.14](https://github.com/ros-navigation/navigation2/blob/1.3.14/nav2_amcl/src/amcl_node.cpp#L170-L180)

## Какие ошибки измерены

На каждой метке скана берём оценку `trajectory.csv` штатного решателя. Между реальными сообщениями `/amcl_pose` решатель переносит последнюю поправку по одометрии. Ошибки считаются в координатах карты по совпадающим меткам без подгонки систем координат. Перед событием берём RMSE XY и максимум абсолютной угловой ошибки на интервале [20; 25) с. Критерий устойчивости задавался перед просмотром результатов — ошибка XY ≤ 0,5 м и абсолютная угловая ошибка ≤ 15° на всех 51 отсчётах интервала в 5 с. Время восстановления отсчитывается от события до начала первого подходящего интервала. Подтверждение наступает через 5 с. Горизонт наблюдения после переноса 90 с. [Расчёт](контроль_переноса.py) · [Распространение коррекции по одометрии](../../solver/solve.py)

| Сценарий | fast / slow | RMSE XY за 5 с до события, м | Макс. ошибка курса до события, ° | Ошибка XY в момент события, м | Устойчивость после события | Ошибка XY в конце, м |
|---|---|---:|---:|---:|---|---:|
| Перенос | 0 / 0 | 0,054 | 1,00 | 6,358 | не достигнута за 90 с | 6,159 |
| Перенос | 0,1 / 0,001 | 0,036 | 0,51 | 6,379 | не достигнута за 90 с | 6,125 |
| Без переноса | 0 / 0 | 0,054 | 1,00 | 0,063 | в допуске все 90 с | 0,013 |
| Без переноса | 0,1 / 0,001 | 0,036 | 0,51 | 0,048 | в допуске все 90 с | 0,023 |
| Перенос с командой глобального поиска | 0 / 0 | 0,054 | 1,00 | 3,111 | через 1,0 с, затем до конца | 0,082 |

В каждом из пяти прогонов решатель обработал 1151 скан и получил 576 обновлений AMCL. После переноса минимальная ошибка положения за всё наблюдение составила 5,874 м в базовом запуске и 5,872 м с изменёнными коэффициентами. Оба фильтра сохраняли ошибочную привязку даже при непрерывном движении и исправном лидаре. Время до успешного восстановления в обоих случаях остаётся неизвестным. [Сценарий и расчёт показателей](контроль_переноса.py)

Диагностический пятый прогон получил одно дополнительное сведение — момент переноса. Перед первым изменённым сканом стенд вызвал сервис `/reinitialize_global_localization`. В журнале AMCL зафиксирована инициализация равномерным распределением. Фильтр вошёл в допуск через 1,0 с после вызова и удерживал его до конца записи. Пятисекундное подтверждение было доступно через 6,0 с. В конце ошибка составила 0,082 м и 0,58°. Это показывает, что на данном переносе глобальный поиск мог восстановить позу по имеющимся сканам. Автоматическое распознавание потери позы и ложные команды сброса требуют отдельной оценки. [Сервис AMCL](https://github.com/ros-navigation/navigation2/blob/1.3.14/nav2_amcl/src/amcl_node.cpp) · [Расчёт времени восстановления](контроль_переноса.py)

Испытание охватывает одну карту, одно направление переноса и один запуск на вариант. Оно показывает, что выбранные коэффициенты сами по себе не обеспечили восстановление в этом случае. По нему нельзя оценить вероятность восстановления, эффект включения механизма в других мирах или частоту ложной смены позы. Фильтр может добавлять случайные частицы при падении быстрой средней оценки относительно медленной. Число таких частиц в этом опыте не измерялось. [Алгоритм пересэмплирования Nav2 1.3.14](https://github.com/ros-navigation/navigation2/blob/1.3.14/nav2_amcl/src/pf/pf.c#L365-L450)

## Как повторить прогоны

Команды Bash выполняются из корня репозитория с образом `mgts-solver:latest` из его Dockerfile. В исследовании пакет в образе сообщил версию 1.3.14, ID образа — `sha256:aeca3014ffba551bc19bf3d741907490d36ed4ca4045b5ead243d22594219604`. При другом имени контекста замените `docker --context mgts` на команду своего Docker. Данные и результаты записываются в новый временный каталог. Случайное состояние штатной реализации инициализируется из системного времени. Входы воспроизводимы, момент сходимости при повторе может измениться. [Dockerfile](../../Dockerfile) · [Инициализация и пересэмплирование фильтра](https://github.com/ros-navigation/navigation2/blob/1.3.14/nav2_amcl/src/pf/pf.c)

```bash
set -e
work=$(mktemp -d)
script="$PWD/research_notes/Локализация инспекционного робота/контроль_переноса.py"
docker --context mgts run --rm --network none \
  -v "$script:/trial.py:ro" -v "$PWD/configs/amcl.yaml:/mgts/configs/amcl.yaml:ro" \
  -v "$work:/work" mgts-solver python3 /trial.py generate /work
mkdir "$work/results"
pids=()
for scenario in clean jump; do
  for mode in base recovery; do
    cfg="$PWD/configs/amcl.yaml"
    if [[ "$mode" == recovery ]]; then cfg="$work/input/recovery.yaml"; fi
    docker --context mgts run --rm --network none \
      -v "$work/input:/input:ro" -v "$cfg:/mgts/configs/amcl.yaml:ro" \
      -v "$work/results:/results" mgts-solver python3 solver/solve.py localize \
      "/input/$scenario" "/results/$scenario-$mode" --map /input/map.yaml \
      --profile /input/profile.yaml --initial 3.7 2.5 1.5707963267948966 --rate 3 \
      > "$work/$scenario-$mode.log" 2>&1 &
    pids+=("$!")
  done
done
for pid in "${pids[@]}"; do wait "$pid"; done
for scenario in clean jump; do
  for mode in base recovery; do
    echo "$scenario $mode"
    docker --context mgts run --rm --network none \
      -v "$script:/trial.py:ro" -v "$work:/work:ro" mgts-solver python3 \
      /trial.py score "/work/truth/$scenario.csv" "/work/results/$scenario-$mode"
  done
done
```

Для диагностического прогона берём те же входы и базовые коэффициенты. Временная копия решателя вызывает штатный сервис ровно один раз перед публикацией скана с индексом 250. Узел AMCL остаётся штатным. [Решатель](../../solver/solve.py) · [Сервис AMCL](https://github.com/ros-navigation/navigation2/blob/1.3.14/nav2_amcl/src/amcl_node.cpp)

```bash
python3 - "$work/oracle.py" <<'PY'
from pathlib import Path
import sys
s = Path('solver/solve.py').read_text()
marker = '            laser.publish(scan)'
assert s.count(marker) == 1
extra = '''            if len(odom_rows) == 250:
                service("/reinitialize_global_localization", Empty, Empty.Request())
                print("Oracle reset before scan", t, flush=True)
'''
Path(sys.argv[1]).write_text(s.replace(marker, extra + marker))
PY
docker --context mgts run --rm --network none \
  -v "$work/input:/input:ro" -v "$PWD/configs/amcl.yaml:/mgts/configs/amcl.yaml:ro" \
  -v "$work/oracle.py:/mgts/solver/solve.py:ro" -v "$work/results:/results" \
  mgts-solver python3 solver/solve.py localize /input/jump /results/jump-oracle \
  --map /input/map.yaml --profile /input/profile.yaml \
  --initial 3.7 2.5 1.5707963267948966 --rate 3
docker --context mgts run --rm --network none \
  -v "$script:/trial.py:ro" -v "$work:/work:ro" mgts-solver python3 \
  /trial.py score /work/truth/jump.csv /work/results/jump-oracle
```
