# Промежуточная проверка интеграции — 26 ноября 2026

Это checkpoint по запросу пользователя, пока продолжаются прогоны; не финальный релиз.

Проверено в этой сессии:

- Исходные 52 Python-теста прошли. Расширенная suite: **72 passed**.
- Собран CPU-образ `mgts-localizers:dev`: KISS-ICP, NDT/GICP, Beluga/VDB и ROS-адаптер.
- Загружены и проверены SHA256 обоих настоящих rosbag из `ivr0ma/hackathon`.
- Проверены парные raw/base облака и LiDAR mount; полные IMU extrinsics отсутствуют.
- Из world-frame облаков A подготовлена вспомогательная карта: 27 875 точек, без собственной
  оптимизации GLIM/RKO. Occupancy: 3623 occupied, 43 596 free, 108 311 unknown ячеек.
- Реальная нормализация B прошла; существующая одометрия поддерживает 1525 из 1526 сканов
  без экстраполяции. Это бортовая LiDAR/IMU одометрия, не ground truth.

Первый контроль неизвестного старта на этой карте:

| Профиль | Наблюдение |
|---|---|
| L0 baseline | Глобальная инициализация отказала: несколько близких по качеству гипотез. |
| L1 Beluga | Обработаны 1526 сканов, подтверждённых глобальных поз нет; распределение осталось неоднозначным. |
| L2 NDT + KISS | KISS прошёл B; прежний bootstrap на парном ICP также отказал. В текущем коде к bootstrap подключены относительные позы KISS; повторная проверка ожидается. |
| L3 Beluga + KISS | Обнаружен пустой список сенсорных connections: AnyReader прочитал LiDAR вместо Odometry. Исправлено; повторный запуск ожидается. |

Высокий overlap у Beluga не принят за доказательство успешной локализации. Без независимого
GT абсолютная точность и доля ложных инициализаций неизвестны. Пороги ради успешного запуска
не ослаблялись. Новые методы пока не рекомендованы в качестве основного режима.

Сборка RKO выявила ошибку владения `unique_ptr` в импортированном bag-export патче.
Исправлены сериализация объекта и move-публикация; повторная сборка и сквозной synthetic smoke
ещё не завершены. Новая полная GLIM/CUDA-сборка в этой сессии не проверялась.

Ещё не завершены: повторные L2/L3, синтетическая матрица с двумя mapping backend, серия seed,
fault-injection matrix, измерение достоверности глобального старта с GT и визуальная проверка RViz.
